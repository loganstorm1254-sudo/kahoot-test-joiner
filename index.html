Frequently Asked Questions

Quick answers before you join a game.

How do I join?

Enter the host’s PIN, choose how many players to add, then select Enter. Use Leave all to disconnect every bot.

Does this work on private quizzes?

Yes for joining. Answer lookup works best on public quizzes; private games guess at first, then learn from each reveal.

Why do bots answer at different speeds?

Known answers are sent immediately. When a bot needs to search, it waits briefly so results can come back before submitting.

Can I use my own player names?

Turn off Random names and set a base name. Each bot gets a number suffix unless you join only one player.

What does the version line mean?

It shows the build in your browser and whether a newer deploy is available. Hard-refresh if an update is ready.

Will the host know these are bots?

They appear as normal players in the lobby. Use responsibly and only where extra players are allowed.
