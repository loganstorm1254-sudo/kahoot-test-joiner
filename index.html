Features

Everything you need to scale up a live session.

Batch join

Send up to 100 players into one game with staggered connections so the host stays stable.

Auto-answer

Bots answer on their own — instantly when the answer key is known, or after a quick web search.

Smart lookup

Public quizzes are matched by title and layout. Private games learn the correct choice after each reveal.

Spaced PINs

Type PINs naturally, like 123 456. Spaces and formatting are handled for you.

Stay connected

Dropped connections retry automatically. Answering resumes when a question is still open.

End-of-game stats

See ranks, scores, and which bot finished on top when the host ends the quiz.

Q&A

Quick answers before you enter a game.

How do I join?

Enter the host’s PIN, choose how many players to add, then tap Enter. Use Leave all to disconnect every bot.

Does this work on private quizzes?

Yes for joining. Answer lookup works best on public quizzes; private games guess at first, then learn from each reveal.

Why do bots answer at different speeds?

Known answers are sent immediately. When a bot needs to search, it waits briefly so results can come back before submitting.

Can I use my own player names?

Turn off Random names and set a base name. Each bot gets a number suffix unless you join only one player.

What does the version line at the bottom mean?

It shows the build running in your browser and whether a newer deploy is available. Hard-refresh if it says an update is ready.

Will the host know these are bots?

They appear as normal players in the lobby. Use responsibly and only in games where extra players are allowed.
